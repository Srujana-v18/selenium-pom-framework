# Selenium POM Framework

This is a Selenium Automation Framework built using:

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

## Project Structure

src/test/java/
├── base/
├── pages/
└── tests/

## Features

- Page Object Model design
- Reusable test components
- TestNG test execution
- Maven dependency management
